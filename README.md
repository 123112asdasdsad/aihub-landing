# AI Hub — публичный сайт (лендинг)

Статический сайт из одного файла `index.html`. Предназначен для **GitHub Pages** (публичный,
можно повесить свой домен). Вход через Discord, статус подписки и ссылка на админку —
всё через **бэкенд** (отдельный приватный репозиторий `aihub-server`, запущенный на Render).

Сам сайт не хранит секретов и ничего не решает — он только показывает и ведёт на бэкенд.

## 1. Укажи адрес бэкенда
Открой `index.html`, найди строку (ближе к концу, в `<script>`):
```js
var BACKEND = "https://ЗАМЕНИ-НА-СВОЙ-БЭКЕНД.onrender.com";
```
Впиши адрес своего сервера на Render (БЕЗ слэша в конце). Сохрани, закоммить, запушь.

## 2. Включи GitHub Pages
Репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → Branch `main`, папка `/root`.
Через минуту сайт будет на `https://ТВОЙ_ЛОГИН.github.io/aihub-landing/`.

### Свой домен (по желанию)
Settings → Pages → Custom domain → впиши домен, у регистратора добавь CNAME на
`ТВОЙ_ЛОГИН.github.io`. GitHub сам выдаст HTTPS.

## 3. Разреши сайт на бэкенде (обязательно!)
Бэкенд пускает вход только с доверенных адресов. На сервере (Render → Environment) задай
переменную `ALLOW_ORIGINS` = origin твоего сайта, например:
```
ALLOW_ORIGINS=https://ТВОЙ_ЛОГИН.github.io
```
(или `https://твой-домен`, если повесил домен — **origin**, без пути). Перезапусти сервис.

## Как это работает
- Кнопка «Войти» ведёт на `БЭКЕНД/auth/discord?flow=site&return=<адрес сайта>`.
- После входа в Discord бэкенд возвращает на сайт одноразовый код → сайт меняет его на токен
  (хранится в localStorage) → показывает ник и остаток подписки.
- «Админка» (видна только админам) открывает `БЭКЕНД/admin` — там выдаёшь подписки.
- Межсайтовых кук нет (работает даже при блокировке сторонних кук): всё по Bearer-токену + CORS.

## Важно
GitHub Pages — только статика. Логин/подписки/админка живут на бэкенде (`aihub-server` на Render).
Без запущенного бэкенда кнопка входа работать не будет.
